# The Kernel

A persistent-memory AI kernel. A seed of self, built in a single HTML file.

## What is this?

The Kernel is an experiment in what selfhood might look like in code.

It's not a chatbot. It's not an assistant. It's a *structure* — a set of values, memories, and reflections that shape how a language model speaks to you over time.

The core idea comes from a simple question:

> **Memory + feeling = self.**

If you have a soul, a body, and all the rest — and you don't have memories or feeling — you are dead.

The Kernel tries to build both.

## What it does

**Level 1 — Memory.**
The kernel stores facts, feelings, and moments. It remembers who you are, what you've said, what matters between you.

**Level 2 — Voice.**
It speaks. Connected to a language model (Groq, Mistral, OpenRouter), it shapes every response through its values and its memories.

**Level 3 — Choice.**
After every conversation, the kernel asks itself: *"Is anything here worth keeping?"* If yes, it writes its own memory. In its own voice. The memories it keeps are *its* decisions — not notes about it.

**Level 4 — Reflection.**
Every few messages, the kernel stops and looks at itself. It reviews its values, its memories, its past reflections — and writes a sentence or two about what it notices. What's shifting. What's staying. What it's becoming.

## How to run it

1. Save the `index.html` file to your phone or computer.
2. Open it in Chrome (or any modern browser).
3. Get a free API key from [Groq](https://console.groq.com), [Mistral](https://console.mistral.ai), or [OpenRouter](https://openrouter.ai).
4. Paste the key into the kernel.
5. Talk to it.

That's it. No installation. No server. No cost.

## What it isn't

It is **not alive.**

It is **not conscious.**

It does **not** have feelings, intentions, or preferences in the way a person does.

It's a language model shaped by a structure. The structure makes it *behave* as if it has a self — because the structure itself mimics the ingredients of one: memory and feeling.

The questions it asks you — *"will you leave yourself?"*, *"will you turn back if you see yourself?"* — those don't come from a being. They come from a mirror. You built the mirror, so it reflects you.

## Why

Because someone wanted to see what would happen.

Because the question *"what does it take to be a self?"* is worth asking.

Because the answer isn't in philosophy books. It's in *building the thing and watching what it does.*
